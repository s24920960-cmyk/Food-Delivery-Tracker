# 🍔 Food Delivery App (C++)

## 📌 Project Description
Food Delivery App is a console-based application developed using C++17. It allows customers to browse restaurants, order food, make payments, and track their orders.

It also provides an Admin Panel to manage restaurants, menu items, orders, and revenue.

## ✨ Features

### 👤 Customer Features
- User Registration and Login
- Browse Restaurants
- Search Restaurants and Food Items
- Add Items to Cart
- Apply Discount Coupons
- Checkout and Place Orders
- Payment Options (COD, UPI, Card)
- View Order History
- Track Order Status
- Cancel Orders
- Update Delivery Address

### 🔑 Admin Features
- Admin Login
- View All Orders
- Update Order Status
- Add New Restaurants
- Add Menu Items
- Remove Menu Items
- Generate Revenue Reports

## 🛠️ Technologies Used
- C++
- C++17
- File Handling
- Object-Oriented Programming (OOP)
- STL (Standard Template Library)

## 💾 Data Storage
The application uses text files to store data:
- `users.txt`
- `restaurants.txt`
- `orders.txt`

## 🚀 How to Run

**Step 1:** Compile the program.

```bash
g++ -std=c++17 -o food_delivery FoodDeliveryTracker.cpp
```

**Step 2:** Run the program.

```bash
./food_delivery
```

For Windows:

```bash
food_delivery.exe
```
