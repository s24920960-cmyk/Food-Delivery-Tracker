# Food Delivery Tracker

## Project Overview
Food Delivery Tracker is a console-based food ordering application developed using C++.

## Features
- Customer registration and login
- Food menu browsing
- Food item selection
- Cart and quantity management
- Bill calculation
- Order placement
- Order history and status tracking
- Admin management of restaurants and menu items

## Technology Used
- Programming Language: C++
- Compiler: GCC / G++
- Interface: Console-based

## Project Purpose
This project demonstrates the basic concepts of C++ programming, functions, conditional statements, loops, data management and file handling.

## Disclaimer
This is an academic demonstration project. Payment and delivery tracking features are simulated.
